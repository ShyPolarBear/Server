## ✏️ Main Feature
- jwt/OAuth을 이용한 로그인
- 매월 랭킹 초기화, 매일 랭킹 업데이트
- 환경 퀴즈(OX/객관식) 제공
- 퀴즈 정답 시 포인트 제공
- 피드 crud, 피드 좋아요 (조회 시 조건에 따라 정렬)
- 댓글 crud, 댓글 좋아요
- 내 정보 조회
  <br><br>
    

## 🔧 Stack

- **Language** : java17
- **Library & Framework** : Spring boot, Spring Security, Spring Data jpa, Querydsl
- **Database** : MySQL
- **ORM** : Jpa
- **Deploy** : AWS(EC2, S3, RDS), Redis, Docker
